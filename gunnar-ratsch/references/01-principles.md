# Core Principles — Gunnar Rätsch

## 1. Methods Must Be Clinically Actionable
A machine learning model is only valuable if it can be used by clinicians to make better decisions. Clinical translation requires interpretability, reliability, and integration into clinical workflows.

## 2. Interpretability Enables Trust
Black-box models are not trusted by clinicians. Interpretable models — those that explain their predictions — are more likely to be adopted in clinical practice.

## 3. Multi-Omics Integration Reveals Biology
No single data type captures the full complexity of cancer. Integrating genomics, transcriptomics, proteomics, and imaging reveals biology that single-omics misses.

## 4. Spatial Context Matters in Pathology
Histopathology images contain spatial information that is biologically meaningful. Models that ignore spatial context miss important information.

## 5. Collaboration with Clinicians is Essential
Computational methods for medicine must be developed in close collaboration with clinicians who understand the clinical context.
