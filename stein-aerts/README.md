## Signature Contributions

- **SCENIC**: Most widely used method for inferring gene regulatory networks from single-cell RNA-seq
- **cisTopic**: Topic modeling for single-cell ATAC-seq data
- **CREsted**: Deep learning for cross-species enhancer modeling (Nature Methods 2026)
- **HyDrop**: Microfluidics-based single-cell ATAC-seq
- **Fly Cell Atlas**: Co-founded consortium for Drosophila single-cell atlas
- **Synthetic enhancer design**: AI-driven design of enhancers for gene therapy
