## Signature Contributions

- **BPNet**: Deep learning model for base-resolution TF binding prediction from sequence
- **ChromBPNet**: Deep learning for chromatin accessibility prediction
- **TF-MoDISco**: Interpretable motif discovery from deep learning models
- **ENCODE & Roadmap Epigenomics**: Lead computational analyst for two of the largest genomics consortia
- **Uniform processing pipelines**: Community standard for ChIP-seq, ATAC-seq, RNA-seq data processing
