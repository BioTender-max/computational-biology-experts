## Signature Contributions

- **Missing value estimation**: Foundational paper on microarray data imputation (2001, highly cited)
- **Bayesian data integration**: Framework for combining heterogeneous genomic data for gene function prediction
- **DeepSEA**: Deep learning model predicting chromatin effects of non-coding variants
- **Sei**: Sequence-based framework for regulatory variant interpretation across hundreds of cell types
- **GIANT**: Tissue-specific gene network inference
- **Autism genomics**: Computational methods for predicting ASD-associated genes
