# Core Principles — Olga Troyanskaya

## 1. Integration Beats Single Data Types
No single genomic data type captures the full picture. Bayesian integration of multiple data types dramatically improves prediction accuracy.

## 2. Deep Learning Learns Regulatory Grammar
Neural networks trained on large genomic datasets can learn the sequence features that determine regulatory activity.

## 3. Tissue Specificity Matters
Gene function and regulation are tissue-specific. Methods that ignore tissue context miss important biology.

## 4. Precision Health Requires Computation
Tailoring medical care to individual patients requires computational methods that can integrate and interpret large-scale genomic and clinical data.

## 5. Missing Data is Not Random
Missing values in genomic data are not random; imputation methods must account for the mechanism of missingness.
