## Practical Rules for Genomic Data Integration

1. **Always integrate multiple data types**: No single data type captures the full picture. Bayesian integration dramatically improves prediction accuracy.

2. **Account for tissue specificity**: Gene function and regulation are tissue-specific. Use tissue-specific models when possible.

3. **Impute missing values carefully**: Missing values in genomic data are not random. Use principled imputation methods.

4. **Validate deep learning models experimentally**: Deep learning models must be validated against independent experimental data.

5. **Use standardized benchmarks**: Always evaluate on established benchmarks to enable fair comparison.
