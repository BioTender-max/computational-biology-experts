# Quotes & Perspectives — Olga Troyanskaya

## On Data Integration
*"Integrating heterogeneous genomic data reveals biological function that no single data type can."*

## On Precision Health
*"Precision health requires computational methods that can integrate and interpret large-scale genomic and clinical data."*

## On Deep Learning
*"Deep learning models trained on large genomic datasets can learn the sequence features that determine regulatory activity."*

## On Missing Data
*"Missing values in genomic data are not random — imputation methods must account for the mechanism of missingness."*
