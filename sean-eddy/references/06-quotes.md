# Sean Eddy — Landmark Quotes

> "Parameters are probabilities rather than arbitrary scores. This isn't just aesthetics — it means the numbers have biological meaning and can be compared across analyses."

> "The genome is full of functional noncoding RNAs. We just haven't been looking for them with the right tools."

> "BLAST is fast and good enough for many purposes. But if you want to find the most remote homologs — the ones that reveal unexpected evolutionary relationships — you need a probabilistic model."

> "An E-value of 0.01 is a promise. If you accept all hits at this threshold, you expect 0.01 false positives. That promise is only valid if the E-value is properly calibrated."

> "Computational biology needs philosophical clarity. Too many papers report results without understanding what the numbers mean."

> "A tool without documentation is not a contribution. Software quality is a scientific value."

> "The forward algorithm is more sensitive than Viterbi for database search. This is not a minor technical point — it changes which homologs you find."
