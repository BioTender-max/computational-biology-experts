## 3 Landmark Papers

1. **Eddy SR (2011).** Accelerated profile HMM searches. *PLoS Computational Biology*, 7(10):e1002195. — Introduced HMMER3; 100-fold speedup over HMMER2 while maintaining sensitivity.

2. **Nawrocki EP, Eddy SR (2013).** Infernal 1.1: 100-fold faster RNA homology searches. *Bioinformatics*, 29(22):2933–2935. — Introduced Infernal 1.1; enables genome-scale noncoding RNA annotation.

3. **Griffiths-Jones S, Bateman A, Marshall M, Khanna A, Eddy SR (2003).** Rfam: an RNA family database. *Nucleic Acids Research*, 31(1):439–441. — Introduced Rfam; now catalogs thousands of RNA families used in genome annotation worldwide.
