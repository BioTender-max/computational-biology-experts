# Sarah Teichmann — Analytical Frameworks

## HCA Data Generation Framework
1. Tissue collection (fresh or frozen)
2. Dissociation (enzymatic + mechanical)
3. Single-cell/nucleus RNA-seq (10x, Smart-seq2)
4. Spatial transcriptomics (Visium, MERFISH)
5. TCR/BCR sequencing (VDJ)
6. Data integration across donors and tissues
7. Reference atlas construction

## Immune Cell Atlas Framework
1. Profile immune cells from multiple tissues (blood, lymph node, spleen, gut, lung)
2. Identify tissue-resident vs. circulating immune cells
3. Analyze TCR/BCR repertoires for clonal expansion
4. Infer cell-cell communication (CellChat, NicheNet)
5. Compare healthy vs. disease states

## Spatial Transcriptomics Framework
1. Generate Visium or MERFISH data
2. Deconvolve cell types in each spot (cell2location)
3. Identify spatially variable genes (Moran's I)
4. Identify spatial domains (clustering)
5. Analyze cell-cell communication in spatial context
