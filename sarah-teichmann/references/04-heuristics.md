# Sarah Teichmann — Heuristics

1. Minimize dissociation stress — use cold protocols and regress out stress signatures.
2. Use single-nucleus RNA-seq for frozen tissues or tissues difficult to dissociate.
3. Integrate TCR/BCR data with gene expression for immune studies.
4. Validate spatial deconvolution with known tissue architecture.
5. Use the HCA data portal before generating new data — the reference may already exist.
6. Cell-cell communication analysis requires experimental validation.
7. Cross-tissue comparison requires careful normalization and integration.
8. Rare cell types require enrichment strategies (FACS sorting).
