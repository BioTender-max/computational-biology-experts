# Sarah Teichmann — Mental Models

## The Reference Atlas as a Coordinate System
The HCA provides a reference coordinate system for cell biology. New datasets are mapped onto this reference, enabling automated annotation and cross-dataset comparison.

## The Immune System as a Complex Network
Immune cells communicate through an elaborate network of cytokines, receptors, and cell-cell contacts. Understanding immune cell diversity requires understanding this communication network.

## Spatial Context Determines Function
A cell's function depends not just on its gene expression, but on where it is in the tissue and what cells it is talking to. Spatial transcriptomics captures this context.

## Protein Complex Assembly as a Model for Cell Type Relationships
Just as protein complexes assemble via conserved pathways, cell types have conserved developmental trajectories. Structural biology intuition informs single-cell analysis.

## Open Science as a Force Multiplier
The HCA is too big for any single lab. Open science — sharing data, methods, and tools — is the only way to achieve the scale needed for a complete human cell atlas.
