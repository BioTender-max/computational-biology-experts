# Sarah Teichmann — Core Principles

1. **The Human Cell Atlas as a reference map.** Just as the HGP created a reference sequence, the HCA creates a reference map of all human cell types.
2. **Cellular diversity is generated by combinatorial gene regulation.** Different TF combinations activate different gene expression programs.
3. **The immune system as a model for cellular diversity.** The immune system has hundreds of distinct cell types — understanding it requires single-cell resolution.
4. **Spatial context is essential.** Cells function in the context of their tissue environment. Spatial transcriptomics captures this context.
5. **Open science accelerates discovery.** The HCA is a global, open consortium — 3,000+ members worldwide.
6. **Structural biology informs single-cell analysis.** Protein complex assembly principles inform how we think about cell type relationships.
7. **Translation requires industry partnerships.** GSK and EnsoCell partnerships translate HCA insights into therapeutics.
