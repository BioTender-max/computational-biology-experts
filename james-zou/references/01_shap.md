# SHAP — SHapley Additive exPlanations

SHAP (2017) is a game-theoretic framework for explaining machine learning
model predictions. Based on Shapley values from cooperative game theory,
it assigns each feature a contribution to each prediction. SHAP is the
most widely used ML interpretability framework, used by millions of
developers worldwide.

**Key features:**
- Model-agnostic (works with any ML model)
- Consistent and locally accurate
- TreeSHAP: exact computation for tree models
- DeepSHAP: approximation for neural networks

**Reference:** Lundberg & Lee, NeurIPS (2017). arXiv:1705.07874
