# Jared Simpson — Core Principles

1. **Signal-level analysis is more accurate than base-level analysis** — Base calling discards information; the raw electrical signal contains more information than the base-called sequence.
2. **Nanopore sequencing enables real-time, portable genomics** — Nanopore sequencers are small, portable, and produce data in real time, enabling genomic surveillance in the field.
3. **Methylation is a first-class citizen** — Nanopore sequencing can detect DNA methylation directly, without bisulfite conversion or other chemical treatments.
4. **Long reads enable new biology** — Long reads can span repetitive regions, resolve structural variants, and phase haplotypes.
5. **Probabilistic models are the right framework for noisy data** — HMMs and neural networks provide a principled framework for interpreting noisy nanopore signals.
6. **Real-time analysis enables real-time decisions** — Nanopore sequencers produce data in real time; real-time analysis algorithms can make decisions before the sequencing run is complete.
7. **Infectious disease genomics requires speed and portability** — Tracking disease outbreaks requires fast, portable sequencing and analysis.
