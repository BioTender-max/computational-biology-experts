## Signature Contributions

- **DHS Index (Nature 2020)**: Most comprehensive index of human regulatory elements — 700+ biosamples, defining the complete landscape of human DNase I hypersensitive sites
- **Roadmap Epigenomics**: Contributed to 111 reference human epigenomes
- **DNA-Diffusion**: Pioneered diffusion models for generating synthetic regulatory elements with desired chromatin accessibility
- **Regulatory variant interpretation**: Methods for interpreting non-coding variants using cell-type-specific regulatory maps
- **Augmented genomics**: Vision for computation-assisted genome science
