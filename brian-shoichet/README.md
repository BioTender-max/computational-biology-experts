## Signature Contributions

- **Ultra-large library docking**: Pioneered docking of billion-compound virtual libraries against GPCRs
- **Colloidal aggregation discovery**: Discovered that many drug-like molecules form nano-scale aggregates causing artifactual inhibition — "the fourth state of matter"
- **DOCK Blaster**: Free web-based molecular docking tool
- **SEA (Similarity Ensemble Approach)**: Predicts new protein targets for known drugs
- **GPCR drug discovery**: Novel ligands for pain, depression, and behavioral disorders
