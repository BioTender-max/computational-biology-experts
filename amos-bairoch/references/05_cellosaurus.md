# Cellosaurus — Cell Line Knowledge Resource

Cellosaurus (2012) is a controlled vocabulary and knowledge resource for
cell lines. Created by Bairoch, it addresses the reproducibility crisis
caused by misidentified and cross-contaminated cell lines. Each entry
includes origin, species, disease, cross-references, and publications.

**Key features:**
- >170,000 cell line entries
- Cross-references to 100+ databases
- Misidentified cell line tracking
- STR profile data for authentication

**Reference:** Bairoch, Journal of Immunological Sciences (2018). PMID: 29805321
