# ExPASy — Bioinformatics Resource Portal

ExPASy (Expert Protein Analysis System, 1993) was the first integrated
bioinformatics web portal. Created by Bairoch's group at SIB, it
integrated Swiss-Prot, PROSITE, ENZYME, and PDB under a single web
interface — the model for all subsequent biological portals.

**Key features:**
- First integrated bioinformatics web portal
- Cross-links between Swiss-Prot, PROSITE, PDB, ENZYME
- Proteomics tools (peptide mass fingerprinting, etc.)
- Still operational at expasy.org

**Reference:** Gasteiger et al., Proteomics (2003). PMID: 12872133
