# PROSITE — Protein Domain and Motif Database

PROSITE (1988) is a database of protein families, domains, and functional
sites, represented as patterns (regular expressions) and profiles. Created
by Bairoch, it was the first systematic approach to protein family
classification and is still maintained by the SIB.

**Key features:**
- Regular expression patterns for functional sites
- Profile HMMs for protein domains
- Cross-linked to Swiss-Prot/UniProt
- Foundation for protein family classification

**Reference:** Hulo et al., Nucleic Acids Research (2006). PMID: 16381852

# ExPASy — Bioinformatics Resource Portal

ExPASy (Expert Protein Analysis System, 1993) was the first integrated
bioinformatics web portal. Created by Bairoch's group at SIB, it
integrated Swiss-Prot, PROSITE, ENZYME, and PDB under a single web
interface — the model for all subsequent biological portals.

**Key features:**
- First integrated bioinformatics web portal
- Cross-links between Swiss-Prot, PROSITE, PDB, ENZYME
- Proteomics tools (peptide mass fingerprinting, etc.)
- Still operational at expasy.org

**Reference:** Gasteiger et al., Proteomics (2003). PMID: 12872133
