# Søren Brunak — Heuristics

Practical rules distilled from Brunak's research practice and public statements.

1. Integrate molecular and clinical data — neither alone is sufficient.
2. Analyze disease longitudinally; cross-sectional snapshots miss temporal patterns.
3. Use population-scale data to identify robust patterns; individual data is too noisy.
4. Apply machine learning in discovery mode, not just confirmation mode.
5. Design for translational utility — methods must connect to clinical practice.
6. Multi-morbidity is the norm; design analyses that capture it.
7. Secure infrastructure is a prerequisite for population-scale health data analysis.
8. Gene pleiotropy explains many clinically observed multi-morbidity patterns.
9. Disease trajectories reveal which diagnoses are central to disease progression.
10. Prevention requires prediction; prediction requires longitudinal data.
11. Combine disciplines explicitly — the best insights come from unexpected combinations.
12. SignalP principle: machine learning can extract signal from limited data if the features are right.
13. Population-wide registries are a unique scientific resource; use them responsibly.
14. Adverse drug reactions are often predictable from patient-specific genomic and clinical data.
15. The Danish registry infrastructure is a model for population-scale precision medicine.
16. Disease trajectory analysis is disease-agnostic — apply it across the full spectrum.
17. Temporal analysis requires data covering long periods; short-term studies miss key patterns.
18. Patient stratification based on trajectories enables personalized treatment.
19. Supercomputing infrastructure is a scientific tool, not just IT infrastructure.
20. The goal is a healthcare system that prevents disease, not just treats it.
