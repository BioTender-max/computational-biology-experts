# Rahul Satija — Core Principles

1. **Integration enables generalization.** Single datasets are limited. Integration across experiments, technologies, and species reveals conserved biology.
2. **Multimodal data captures cell state more completely.** No single modality captures the full state of a cell. WNN learns the optimal combination.
3. **Scalability without sacrificing accuracy.** Methods must scale from 10,000 to 10,000,000 cells. Sketch-based analysis enables this.
4. **Reference atlases enable automated annotation.** Build once, annotate forever. Azimuth maps new datasets onto curated references.
5. **Statistical rigor matters.** SCTransform replaced log-normalization because it is more statistically principled.
6. **Open source accelerates science.** Seurat is free, well-documented, and community-maintained.
7. **Validate with known biology.** Every new method must be validated against known cell types and biological relationships.
