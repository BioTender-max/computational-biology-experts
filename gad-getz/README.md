## Signature Contributions

- **MutSig**: Most widely used algorithm for identifying significantly mutated genes in cancer
- **MuTect**: Gold-standard algorithm for somatic mutation detection from tumor-normal pairs
- **GISTIC**: Identifies significantly amplified/deleted genomic regions across tumor cohorts
- **TCGA GDAC**: Co-led the TCGA Genome Data Analysis Center at the Broad
- **Terra/FireCloud**: Cloud-based platforms for large-scale cancer genomics pipelines
- **IGV**: Co-developed the Integrative Genomics Viewer
