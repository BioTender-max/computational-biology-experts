# Rob Knight — Heuristics

1. Rarefy before diversity analysis — unequal sequencing depth confounds comparisons.
2. Use phylogenetic metrics (UniFrac) for beta diversity.
3. 16S rRNA for community composition; shotgun for function.
4. Collect metadata carefully — it determines biological interpretation.
5. Batch effects are pervasive — include technical controls.
6. Large sample sizes are essential (>100 samples minimum).
7. Use ASVs (DADA2/Deblur) instead of OTUs for new studies.
8. Validate microbiome-health associations with FMT experiments.
