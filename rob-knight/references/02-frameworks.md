# Rob Knight — Analytical Frameworks

## QIIME 2 16S rRNA Analysis Framework
1. Import raw sequencing data
2. Quality control and denoising (DADA2 or Deblur)
3. Taxonomic classification (SILVA or Greengenes2)
4. Phylogenetic tree construction
5. Diversity analysis (alpha and beta diversity)
6. Statistical testing (PERMANOVA, Kruskal-Wallis)
7. Visualization (Emperor, barplots)

## Earth Microbiome Project Framework
1. Standardized sample collection (swabs, preservation)
2. Standardized DNA extraction (MoBio PowerSoil)
3. V4 16S rRNA amplification (515F/806R)
4. Illumina MiSeq sequencing
5. QIIME 2 analysis with SILVA taxonomy
6. Open data sharing (Qiita platform)

## Microbiome-Health Association Framework
1. Collect samples from cases and controls
2. Profile microbiome composition (16S or shotgun)
3. Test for differential abundance (LEfSe, ANCOM)
4. Validate in independent cohort
5. Establish causality with FMT or germ-free experiments
