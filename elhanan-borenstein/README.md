## Signature Contributions

- **Community metabolic modeling**: Pioneered constraint-based metabolic modeling of microbial communities (MICOM, NetCooperate)
- **Microbiome-metabolome integration**: Methods for predicting metabolite profiles from metagenomic data
- **Species interaction inference**: Computational methods for inferring ecological interactions from metagenomic data
- **Multi-omic microbiome analysis**: Frameworks for integrating metagenomics, metatranscriptomics, and metabolomics
- **Disease applications**: IBD, Crohn's disease, autism, dietary fiber metabolism
