# Curtis Huttenhower — Analytical Frameworks

## bioBakery Metagenomics Framework
1. Quality control (Kneaddata: host removal, quality trimming)
2. Taxonomic profiling (MetaPhlAn4)
3. Functional profiling (HUMAnN3)
4. Normalization (TSS for relative abundance)
5. Statistical analysis (MaAsLin2 for multivariable associations)
6. Biomarker discovery (LEfSe)
7. Visualization (GraPhlAn, hclust2)

## HMP2/iHMP Multi-Omics Framework
1. Metagenomics (MetaPhlAn + HUMAnN)
2. Metatranscriptomics (active gene expression)
3. Metabolomics (small molecule metabolites)
4. Host transcriptomics (biopsy RNA-seq)
5. Serology (host immune markers)
6. Integration (multi-omics factor analysis)

## Microbiome-Disease Association Framework
1. Collect longitudinal samples from cases and controls
2. Profile taxonomy (MetaPhlAn) and function (HUMAnN)
3. Multivariable association analysis (MaAsLin2)
4. Biomarker discovery (LEfSe)
5. Validate in independent cohort
6. Mechanistic follow-up (germ-free mice, FMT)
