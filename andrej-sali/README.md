## Signature Contributions

- **MODELLER**: The most widely used program for comparative protein structure modeling (millions of downloads)
- **IMP (Integrative Modeling Platform)**: Formal framework for integrative/hybrid structure determination
- **Nuclear Pore Complex**: Determined configuration of 550 proteins — largest integrative structure ever solved
- **PDB-Dev**: Co-founded the worldwide archive for integrative/hybrid structures
- **Global Blood Therapeutics**: Co-founded; developed voxelotor for sickle cell disease (acquired by Pfizer 2022)
