## Signature Contributions

- **Coalescent theory**: Foundational algorithms for computing likelihoods under the coalescent model
- **Population genetics inference**: Efficient methods for demographic history inference from genomic data
- **Probabilistic genomics**: Models for haplotype phasing, structural variant detection, RNA splicing
- **Deep learning for genomics**: Variant effect prediction and single-cell genomics analysis
