# Frameworks — Yun Song

## Coalescent-Based Inference
1. **Data**: Genomic sequences from a population sample
2. **Model**: Coalescent model with demographic parameters
3. **Likelihood computation**: Efficient algorithms for computing coalescent likelihoods
4. **Inference**: Maximum likelihood or Bayesian inference of demographic parameters
5. **Validation**: Compare inferred history to independent data

## Probabilistic Genomics Pipeline
1. **Data preprocessing**: Quality control, alignment, variant calling
2. **Model specification**: Define probabilistic model for the data
3. **Inference**: Efficient algorithms for posterior computation
4. **Uncertainty quantification**: Report credible intervals, not just point estimates
5. **Validation**: Validate on held-out data or independent datasets
