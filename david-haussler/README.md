# David Haussler

**UCSC Genomics Institute · HHMI Investigator**

David Haussler is a computational biologist and computer scientist at the
University of California, Santa Cruz (UCSC), where he directs the UCSC
Genomics Institute. He is an HHMI Investigator and a member of the National
Academy of Sciences. Trained in computer science, he pioneered the application
of Hidden Markov Models to biological sequence analysis and led the team that
assembled the first working draft of the human genome sequence (2000). He
created the UCSC Genome Browser — the most widely used genome visualization
tool in biology — and co-leads the Human Pangenome Reference Consortium.

## Key Contributions

- **UCSC Genome Browser** (2002) — most widely used genome visualization tool
- **Human Genome Assembly** (2000) — first public working draft
- **Hidden Markov Models** — HMMER, Genscan, profile HMMs for biology
- **Ultraconserved Elements** (2004) — 481 segments 100% identical across mammals
- **Human Pangenome Reference** (2023) — graph-based reference capturing diversity
- **GA4GH** — co-founder, global genomic data sharing standards
