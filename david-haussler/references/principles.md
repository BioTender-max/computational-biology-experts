# UCSC Genome Browser

The UCSC Genome Browser (2002) is the most widely used genome visualization
tool in biology. Created by David Haussler's group at UCSC, it displays
annotated genome sequences with tracks for genes, conservation, regulatory
elements, and thousands of user-contributed datasets.

**Key features:**
- Multi-species comparative genomics tracks
- ENCODE regulatory annotation integration
- Custom track upload for user data
- REST API for programmatic access

**Reference:** Kent et al., Genome Research (2002). PMID: 12045153

# Hidden Markov Models in Sequence Analysis

Haussler's group pioneered the application of Hidden Markov Models (HMMs)
to biological sequence analysis. The HMMER software package implements
profile HMMs for protein family detection and is the basis for Pfam.

**Key contributions:**
- Pair HMMs for sequence alignment
- Profile HMMs for protein family modeling
- Generalized HMMs for gene finding (Genscan)
- Theoretical foundations of biological sequence analysis

**Reference:** Krogh et al., Journal of Molecular Biology (1994). PMID: 8107089
