# Peer Bork — Heuristics

1. Use STRING for protein function prediction — guilt by association is powerful.
2. Enterotypes are useful but imperfect — use as a descriptive framework.
3. Comparative metagenomics requires large sample sizes.
4. Protein domain architecture is an evolutionary record — use SMART and Pfam.
5. iTOL for phylogenetic visualization.
6. Integrate multiple evidence types in STRING.
7. Validate key STRING interactions experimentally.
8. Don't ignore unannotated genes — they may be the most interesting.
