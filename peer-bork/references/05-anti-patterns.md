# Peer Bork — Anti-Patterns

## Enterotype Oversimplification
The human gut microbiome is not truly discrete. Continuous variation exists within and between enterotypes.

## STRING Score Threshold
STRING scores are confidence scores, not probabilities. Always validate key interactions experimentally.

## Metagenomics Assembly Chimera
Metagenomic assembly can produce chimeric contigs. Always validate assemblies with read mapping.

## Functional Annotation Gap
Many metagenomic genes have no known function. Don't ignore unannotated genes.
